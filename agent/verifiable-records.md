# 用可核对记录支撑 AI 流程和交接
把系统内可核验的记录作为协作依据，而不只依靠人的回忆。以下为可执行的工作流，写明哪些状态变更必须留记录、哪些步骤加校验、人工复核路径怎么留。  
步骤一：列出必须留记录的状态变更  做什么：先确定哪些状态变更不能只靠口头信息。  怎么做：按判据筛选——不可逆的操作、影响较大的操作、跨人或跨系统的交接、会被后续自动化流程当作输入的状态；把这些变更逐条列成清单（如转账、确认、交付验收）。  产出与通过：有一份明确清单；清单外的步骤可以口头沟通，清单内的步骤没有记录即视为未发生。  
步骤二：每条记录写全四要素  做什么：让记录本身可核对。  怎么做：每条记录包含——时间、责任人、凭据（系统内生成的凭证、单据或文件）、确认结果（谁确认、结论是什么）；凭据取自系统内可信记录，不以回忆补写。  产出与通过：任取一条记录都能回答「何时、谁、凭什么、确认了什么」；缺一项就退回补齐，不允许用说明性文字代替凭据。  
步骤三：在关键步骤加校验  做什么：对容易把错误继续传下去的步骤加明确校验。  怎么做：在不可逆或高影响的步骤前加校验点，检查上一步的记录是否齐全、字段是否与凭据一致、重复录入是否已消除；校验不通过就阻断，不进入下一步。  产出与通过：自动化流程以记录为依据运行；错误在校验点被拦下，而不是被带到下游。  
步骤四：留出人工复核路径  做什么：系统记录作为协作依据，同时保留人工复核的入口。  怎么做：写明谁可以复核、复核时看哪些凭据、发现不一致时回退到哪一步、更正后如何留下新记录；复核动作本身也留记录。  产出与通过：任何一条记录都能被人工追到原始凭据；更正有痕迹，不覆盖原记录。  
步骤五：对外材料忠实反映实际履约  做什么：对外材料要符合真实工作和审核要求。  怎么做：材料从实际履约记录生成，逐项可回溯到对应凭据；记录有缺口时先补记录，不用虚假材料填补。  产出与通过：对外材料的每项内容都有对应记录支撑，后续学习者不会从错误记录中学到错误经验。  
边界  各业务用哪些记录、由谁确认、保留多久，留给相应的流程规范，本文不越界；本工作流只规定记录要素、校验与复核的通用做法。  提案原文说明这些发言明确了可靠记录和核验的要求，但不同业务的记录种类、确认人和保留期限仍需在相应流程规范中明确。  原始讨论上下文、实践状态与结果表述仍待核对；如有后续数据或制度版本，可补充后再作为成熟案例迁移。
