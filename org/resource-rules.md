# 让资源支持与组织规则共同演进
以下为可执行的机制条目，写明资源请求要说明什么、提案走什么路径、谁有权调整或停止项目，以及公司与基地的协作边界。  
条目一：资源请求要说明价值、成本与责任  规则内容：申请公司评审、证明、基础设施或其他支持时，必须写明三件事——这项支持对应的价值、需要公司付出的成本、由谁对结果负责。三者缺一，不进入受理。  适用范围：基地向公司提出的一切资源请求。  执行与调整权：由提案人填写，基地按条目核对；核对口径的调整走组织决议。  
条目二：资源取得走两条路径  规则内容：资源支持需要有可说明的价值依据，可以用代金券购买，也可以通过实训基地或联盟的决议推动；不靠向创始人寻求个别例外。  适用范围：已受理的资源请求。  执行与调整权：代金券路径按既定兑换规则执行；决议路径由基地或联盟形成决议；公司按决议或兑换规则提供支持。  
条目三：提案路径  规则内容：鼓励成员通过制度提案争取资源，把资源分配变成规则化流程，而不是个别协商。  适用范围：成员发起的资源与规则类提案。  执行与调整权：提案提交组织机制（基地或联盟代表大会）讨论、表决、归档；公司不单独开辟例外通道。  
条目四：谁有权调整或停止项目  规则内容：项目层面鼓励成员对方向做取舍，必要时缩小或终止项目；项目方向与范围由承担项目的成员按组织机制调整，公司可在项目与公司当前目标不符时通过组织机制提出停止。  适用范围：方向过宽、停滞或与公司当前目标不符的项目。  执行与调整权：调整或停止的决定须走组织机制并留记录，不由个人口头决定；公司资源有限时按条目一的价值依据排序。  
条目五：评价重点  规则内容：评价重点包括独立决策和团队协作，不只看题目最终是否成功。  适用范围：项目复盘与成员评价。  执行与调整权：由组织机制在复盘时执行，结论归档。  
条目六：公司与基地的协作边界  规则内容：公司与实训基地尽量分别协作，各自职责内的决定不相互代办；需要共同处理的事项通过组织机制对接，形成书面记录。  适用范围：双方的所有协作事项。  执行与调整权：各自在职责范围内决策；跨边界事项提交组织机制协商，不由单方默认代为决定。  
边界  规则仍随实践调整，照实写：提案原文记录内部讨论明确了资源边界和提案方式，以及公司与实训基地分别协作、需要共同时通过组织机制对接的安排；这些规则仍会随实践调整，本方案不把它们写成定稿制度。
